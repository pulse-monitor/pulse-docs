# Dashboard

首页要回答的问题只有一个：**现在有什么值得我关注？**

## 汇总区

顶部六个数字，是全部节点的合计：

| | 说明 |
|---|---|
| 内存用量 | 已用 / 总量 |
| 硬盘用量 | 已用 / 总量 |
| 剩余价值 | 按到期时间线性折算的未使用金额，另附总价与年化 |
| 累计流量 | 当前计费周期内的上下行合计 |
| 实时上行 / 下行 | 全部节点当前速率之和 |

右侧地球按 IP 点亮机器所在国家，右上角是在线 / 离线台数。
把鼠标放到某个国家上会显示那个国家的机器明细。
GeoIP 库在本地，**IP 不外传**。

想按地区看的话用下面的分组 tab —— 地球是概览，筛选交给 tab。

## 即将到期

7 天内到期（含已过期）的机器出现在汇总区下方。多于一台时会轮播 ——
它是提醒，不该把服务器卡片挤出屏幕。

剩余天数会变色：已过期红、≤ 3 天橙、其余正常。已过期的排最前面。

## 服务器卡片

每台一张卡，两种视图（右上角切换）：

- **卡片视图** —— 一行最多四张，适合看资源水位
- **列表视图** —— 一行一台，适合台数多时快速扫

卡片上有 CPU / 内存 / 硬盘 / 流量四个进度条、上下行速率、剩余天数、
以及延迟和丢包的小图。

顶部可以按地区筛选，或者只看即将到期的。

## 单机详情

点卡片进详情页：硬件与系统信息、当前计费与流量状态，
以及 CPU 与负载、内存、磁盘、网络速率、延迟、丢包六张图表。

时间跨度可选实时 / 6 小时 / 1 天 / 7 天 / 30 天 / 1 年，
数据粒度自动跟着切层，页面右上角会写明当前用的是哪一层、多少个点。

## 采不到就说采不到

采不到的指标**不会显示 0**，那一行直接隐藏或标为不可用。

比如温度只有 Linux 采得到（Windows 要 WMI + 管理员、 macOS 要 SMC 特权访问，
按最小权限原则都不做）—— 在这两个平台上你看到的是「不可用」，
而不是一个骗人的 `0°C`。
