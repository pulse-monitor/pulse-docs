# 服务器管理

后台（`/admin`）里管理服务器条目。

## 添加一台

新建条目时 Pulse 会为它生成一个**独立 token**，并给出对应的 Agent 安装命令。
把命令贴到目标机器上执行即可 —— 命令里已经带好了 Server 地址和这台机器的 token。

::: tip 地址来自 PULSE_PUBLIC_URL
安装命令里的 Server 地址取自 `PULSE_PUBLIC_URL`。装在别的机器上时这个必须设对，
否则 Agent 连不上。见[配置](/install/config)。
:::

## 可以改什么

| 字段 | 说明 |
|---|---|
| 名称 | 显示名 |
| 分组 | 用于筛选和按组设阈值 |
| 备注 | 只在后台可见 |
| 购买 / 评测链接 | 方便续费时找回商家页面 |
| 隐藏 | 从公开页隐藏，后台仍可见 |
| 国家 / 地区 / 经纬度 | 默认按 IP 自动判断，也可手动锁定 |

价格、计费周期、到期时间见[成本与到期](/usage/billing)；
流量配额与统计口径见[流量](/usage/traffic)。

## 排序

列表顺序可以手动拖动调整，顺序保存在 Server 端，对所有访客一致。

## 重新生成 token

token 泄露或机器易主时可以重新生成。**旧 token 立即失效**，
那台机器上的 Agent 会掉线，需要用新命令重装。

## 运行期配置

采样间隔、上报哪些指标、网卡包含 / 排除规则这些可以按机器下发，**秒级生效**，
不用重装 Agent。

Agent 收到配置后会先做校验再应用 —— Server 下发一个荒谬的值不会让 Agent 出问题。

## 触发升级

如果 Agent 构建时内置了 minisign 公钥，后台可以触发它自更新到指定版本。
没有内置公钥时这个功能整体关闭， Agent 会如实上报 `self_update: false`。
详见 [Agent 安全](/security/agent)。

## 删除

删除条目会一并删掉它的历史数据。那台机器上的 Agent 会因为 token 失效而掉线，
但**不会**被卸载 —— Pulse 没有远程执行的能力，卸载要自己上机器操作。
