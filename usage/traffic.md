# 流量

流量按**计费周期**统计，不是自然月 —— 商家按什么周期给你额度，这里就按什么周期算。
周期开始时归零，历史归档保留。

## 配额与告警

可以给每台机器设流量配额，超过阈值触发[通知](/usage/notify)。

统计口径有四种，按你和商家的约定选：

| 口径 | 用在什么场景 |
|---|---|
| 只统计上行 | 大多数 VPS 只计出站 |
| 只统计下行 | 少数场景 |
| 双向取大 | 取上下行中较大的那个 |
| 双向求和 | 上下行相加 |

网卡过滤（排除 `lo`、 docker 网桥这类虚拟接口）见[安装选项](/install/agent#网卡过滤)。

## Agent 重启不会丢流量

Agent 记的是网卡的累计计数器。重启后计数器归零， Server 会认出这是重启而不是
流量倒退，按「重启前的累计值 + 重启后的新增」继续算。机器重装同理。

## 那断线期间的流量呢

Agent **不缓存**断线期间的采样，所以那段时间的**速率曲线**是空的。

但**累计流量不会丢** —— 因为累计值取自网卡计数器本身，重连后第一次上报就带着
断线期间涨上去的总量。也就是说：图上会缺一段，总数是对的。
