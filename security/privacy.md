# 隐私

Pulse 是自托管的：数据留在你自己的基础设施里，不会因为「用了 Pulse」
而天然需要上传给第三方。

## GeoIP 在本地

判定机器所在国家用的是 [DB-IP Lite](https://db-ip.com/db/lite.php) 数据库，
**下载到本地后离线查询**。

IP 地址不会发给任何第三方查询服务。

数据库每周检查一次更新，拉不到就继续用本地缓存，不影响运行。
完全断网的环境可以手动放好文件。

## 访客标签

页脚显示访客自己的 IP / 系统 / 浏览器。

这些**不落库、不上报**，只在那一次请求里算出来返回，纯粹是给你自己看的。
不想要就设 `PULSE_VISITOR_BADGE=false`。

## Server 会连哪些外部地址

只有三个，都能关：

| 用途 | 怎么关 |
|---|---|
| 汇率（Frankfurter 兼容接口） | 不填价格就不会用到；也可以用 `PULSE_RATE_BASE_URL` 换成自建源 |
| GeoIP 数据库更新 | 手动放好文件后可以断网 |
| Agent 版本检查 | 不配自更新即可 |

## Agent 会连哪些外部地址

**只连你的 Server。** 没有遥测、没有版本上报、没有任何别的出网。

自更新开启时会额外连一次你自己配置的下载源 ——
那个地址从本地配置读， Server 影响不了它。

## Agent 不采集什么

| | 为什么 |
|---|---|
| 进程命令行 | 命令行里常含密码 |
| 机器指纹（`product_serial`、`product_uuid`） | 监控用不着，泄露了却很麻烦 |
| 文件内容 | 不在职责范围内 |

这几条在 CI 里有断言，见 [Agent 安全](/security/agent)。

## 公开页

面板首页默认是公开的（不用登录就能看）。不想公开：

```bash
PULSE_PUBLIC_MODE=private
```

也可以按机器设「隐藏」—— 从公开页隐藏，后台仍然可见。
