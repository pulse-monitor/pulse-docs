# 流量与账单

## 价格的三个取值

价格字段有三种语义，不是普通数字：

| 值 | 含义 |
|---|---|
| `-1` | **免费**（白嫖来的机器，卡片上标「免费」） |
| `0` | **不显示**（还没填，或者不想公开价格） |
| `> 0` | 正常显示金额 |

## 计费周期

支持月付、季付、半年、年付、两年、三年、一次性。周期日界按面板时区算。

**「剩余价值」按到期时间线性折算**：还剩 30 天的年付机器，剩余价值就是年费的 30/365。
免费机器（价格 -1）的剩余价值恒为 0 —— 不会算出个负数来。

## 到期提醒

7 天内到期（含已过期）的机器会出现在首页的「即将到期」，卡片上剩余天数变色：

- 已过期 → 红
- ≤ 3 天 → 橙
- 其余 → 正常

**已过期的也会列出来**，排在最前 —— 一台悄悄过期的机器正是最需要被看见的。

开了自动续费的机器在宽限期内会标「续费中」，不当成过期。

## 汇率

多币种会自动折算成 `PULSE_DISPLAY_CURRENCY`。汇率每天拉一次，四级降级：

1. 用最新汇率
2. 拉不到就用最后一次成功的值，页面标注「汇率数据已过期」
3. 某个币种压根没有汇率 → **这台机器不计入总价值**，页面标注「N 台的货币没有汇率」
4. 支持在后台人工填汇率，优先级最高

> 会让金额算不准的情况一律**说出来**。不说才是撒谎。

## 流量统计

流量按**计费周期**统计，不是自然月。周期开始时归零，历史归档保留。

- 可以设配额，超过阈值触发告警
- 支持只统计上行 / 只统计下行 / 双向取大 / 双向求和四种口径
- 网卡过滤见[安装选项](/install/agent#网卡过滤)

### 探针重启不会丢流量

探针记的是网卡的累计计数器。重启后计数器归零，面板会认出这是重启而不是流量倒退，
按「重启前的累计值 + 重启后的新增」继续算。机器重装同理。
